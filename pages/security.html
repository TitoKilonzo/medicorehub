Patient Data Security
is Non-Negotiable

MediCore Hub is built on a security-first architecture, independently audited annually, and fully compliant with Kenya's Data Protection Act 2019.

Security Architecture

Defence in Depth

Multiple independent security layers — so that no single failure compromises patient data.

AES-256 Encryption

All patient data encrypted at rest using AES-256-GCM. All data in transit protected by TLS 1.3 with certificate pinning for mobile clients. Keys managed via AWS KMS with customer-managed master keys.

Role-Based Access Control

Granular permission sets mapped to clinical cadre — CHW, nurse, clinician, pharmacist, lab technician, administrator. No user can access data outside their approved role. Configurable per-facility.

Complete Audit Trail

Every data access, modification, and export logged with user identity, timestamp, and IP address. Audit logs are immutable, stored in a separate ledger system, and available for regulatory review on demand.

Business Continuity

Automated geo-redundant backups every 15 minutes. Recovery Point Objective of 15 minutes. Recovery Time Objective of 4 hours. Annual disaster recovery drills documented and shared with clients.

Multi-Factor Authentication

TOTP-based MFA enforced for all administrative and clinician accounts. Single Sign-On supported via SAML 2.0 for facilities with existing Active Directory or LDAP infrastructure.

Penetration Testing

Annual independent penetration tests by accredited third parties. Vulnerability disclosure programme with responsible disclosure policy. Critical vulnerabilities patched within 24 hours under SLA.
